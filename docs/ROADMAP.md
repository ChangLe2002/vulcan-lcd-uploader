# 路线图

## 已完成

- 图像上传（GIF / PNG / JPEG → pak），与官方一致的编码管线
- 播放列表轮播，每项独立停留时间
- 设备端监控上屏（GPU / CPU 两种布局）
- 设备设置：亮度、开机图、开机动画
- 缓存清理（安全 / 彻底两种模式）
- 素材库、托盘常驻、开机自启、独立模式
- 深色新界面与浅色旧界面
- 首次启动免责声明与使用说明
- 450+ 项自动化测试、CI、两种安装包

## 计划中

| 项 | 说明 | 状态 |
| --- | --- | --- |
| 开机图验证 | 已按反编译结论改为发送短名 `img1`，待更多机型确认 | 待验证 |
| 时间屏保 | 设备支持时间帧，界面尚未接入 | 待开发 |
| 单指标组合屏 | 反编译中存在 One/Two 帧结构 | 待开发 |
| 多语言界面 | 目前仅简体中文 | 待开发 |
| 自动更新检查 | 需要网络能力，与"不联网"原则冲突，需讨论 | 待定 |

## 明确不做

- **双屏布局**：需要目前未见的设备形态
- **更多监控指标**：风扇/显存页必须带电压字段，消费级主板读不到，会显示 0
- **刷机 / 恢复出厂 / 固件写入**：超出项目边界，风险不可控
