# 常见问题排查

## 设备与串口

### 提示「无法打开 COMx」或「拒绝访问」

串口是**独占**的，同一时间只能有一个进程使用。

| 原因 | 处理 |
| --- | --- |
| iGame Center 服务在跑，但勾了「独立模式」 | 取消勾选，或执行 `sc stop iGameCenterService` |
| 官方软件的其他进程占用 | 退出 iGame Center 托盘程序 |
| 上一轮操作没释放 | 等 3–5 秒再试；仍不行就重启软件 |
| 端口号变了 | 点「扫描」，或拔插一次设备 |

### 01 卡片显示「独立模式 · 未安装官方服务」

这是正常状态：说明系统里没有 iGame Center 服务，工具会直接使用串口。
如果其实装了官方软件，说明服务名被改过，可在「文件 → 独立模式」取消勾选后重启软件。

### 上传成功但清单里没有文件

设备只接受**连续编号**的槽位（`img1`、`img2`…）。如果中间有空洞，设备会静默丢弃。
先看「可用内存」是否够，再点一次上传；仍失败请用「清理设备缓存 → 彻底清理」整理槽位。

### 传过的文件消失了，空间也没回来

官方服务启动时会移除它不认识的槽位，但**不会释放空间**。
用 **文件 → 清理设备缓存 → 彻底清理**（等价于官方图库的垃圾桶）回收，
实测可回收数十 MB。

### 设备像"卡死"：写入有应答，列表却不更新

给屏幕**断电 10 秒**再上电即可恢复。这是设备固件的问题，不需要重装软件。

## 安装

### 安装包报 `Error 5` / `is-XXXX.tmp 拒绝访问`

系统禁止未签名程序往 `%TEMP%` 写文件，而 Inno Setup 必须先解压到那里。
改用 `portable.zip` 安装方式（只调用系统自带工具，不写 `%TEMP%`）。

### 安装后快捷方式打不开 / 提示找不到程序

程序被移动过。重新运行一次 `install.cmd` 修复快捷方式，或手动把快捷方式指向
`<安装目录>\VulcanLCDUploader.exe`。

### 想装到别的盘

安装时改路径即可。**不要装到 `C:\Program Files`**：程序会往自己目录写日志与配置，
那里没有写权限。绿色包默认装到 `%LOCALAPPDATA%\Programs`，可以整体移动到任何有写权限的位置。

## 运行时

### 界面卡顿 / 崩溃

- 退出 **「游戏加加」(GamePP)** 等带 overlay 注入的软件（会注入 Qt 进程导致崩溃）
- 退出其他屏幕录制 / 帧生成工具
- 若仍崩溃，用 `--debug` 启动并把 `logs\` 下的日志和「导出调试报告」发给作者

### 关闭窗口后找不到了

默认最小化到托盘（右下角通知区域），双击图标恢复。
可在「文件 → 关闭窗口时最小化到托盘」关掉这个行为。

### 托盘时占用多少资源

隐藏到托盘后所有轮询停止：**CPU 约 0%，内存约 20 MB**。窗口可见时约 1% 单核。

### 画质和官方略有差异 / 编码偏慢

编码优先用 FFmpeg（与官方相同的滤镜链）。如果系统里没有 FFmpeg，会自动退回 Pillow 编码：
功能正常，但 JPEG 质量与速度略有差别。想要完全一致，安装 FFmpeg 并加入 PATH 即可：

`powershell
winget install Gyan.FFmpeg
`

### 上传很慢 / 编码很久

编码是 FFmpeg 逐帧 JPEG，大尺寸长 GIF 需要几秒到几十秒，进度条会显示剩余时间。
把素材裁到 1024×240 以内可以明显加快。

## 监控

### 「上屏」后屏幕没有变化

- 确认「上屏内容」选择了布局
- 设备只接受它支持的指标帧，若温度等字段读不到会显示 0
- 点「停止上屏」再点「上屏」重试

### CPU 温度 / 电压读不到

Windows 下消费级主板不暴露这些传感器，工具只显示能读到的指标（CPU 占用/频率/内存、
GPU 负载/温度/频率/显存），不做假数据。

## 其他

### 支持哪些显卡

目前针对 iGame 火神 RTX 50 系（设备自报 LCD5A，1024×240）。其他型号未经测试，协议可能不同。

### 会不会影响保修

工具只通过官方同样的串口协议读写屏幕内容，不修改显卡固件。但**非官方用法本身存在风险**，
请自行评估。详见软件内免责声明。
